key_ideas:
- title: Verification is where the time goes
  body: Agents produce pull requests faster than people can review them. The leverage is in review agents tuned on your own incidents, proof attached to every change, and risk scores that route the dangerous paths to owners.
- title: Own the harness, rent the model
  body: OpenAI's planned cutoff of Cursor showed that the model under a tool can vanish on a contract date. Keep harness, memory and model decoupled, and keep private evals so a swap is a measured decision, not an outage.
- title: Factories are team infrastructure
  body: Personal agent setups create runaway token spend, insecure skills and huge productivity gaps. The fix is shared, code-defined, measured agent systems the team improves together, at the cost of some individual choice.
- title: Expect 4–5×, earned one bottleneck at a time
  body: Augment's org-wide numbers show roughly 4.5× more output per developer over nine months with nearly all code AI-written. Large and real, nowhere near 100×, and built by fixing each bottleneck as it appeared.

  - tag: Experiment
    headline: Add Verification, Impact and Rollback cost to agent PRs
    body: 'A two-week experiment adapted from Warp''s merge-risk approach: make the agent show its proof and its blast radius before a person spends time on review.'
    steps:
    - 'Add three fields to the PR template for agent-authored changes: Verification (a link to a test run, screenshot or short recording), Impact (low, medium or high) and Rollback cost.'
    - Add one line to your agents file telling the agent to fill in all three before requesting review.
    - Route anything marked high impact to a code owner automatically.
    measure: Median time from ready-for-review to merged, and revert count, for the next two weeks versus the previous two. Faster reviews with steady reverts means it works; more reverts means the Verification field is too easy to satisfy.
    links:
    - label: Warp
      url: https://www.warp.dev/blog/agent-code-review-bottleneck
