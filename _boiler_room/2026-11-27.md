  items:
  - tag: Case study
    headline: Use production as the oracle
    body: 'Anthropic called the model once per request and replayed its reply into the Rust service, so nothing ran twice against billing or limits. The versions were compared step by step: accept or reject, settings, each prompt piece, tokens, output. Records kept only the shape of a difference, never customer text, and were counted by bug rather than by request. Input matches rose from 24% to 99.6%.'
    links:
    - label: Anthropic
      url: https://www.anthropic.com/research/migrating-api-to-rust
  - tag: Harness engineering
    headline: Three loops, with a person on the seam
    body: 'A coordinating agent gave each new fingerprint to a worker agent and opened a Slack thread for engineers. Inner loop: the worker reproduced the difference in a sandbox, with prompt checks under a second, and added a failing test. Outer loop: after review and deploy, agents watched shadow traffic for the fingerprint to vanish. Memory loop: about 60 review comments became rules, lints and a merge check.'
    links:
    - label: Anthropic
      url: https://www.anthropic.com/research/migrating-api-to-rust
  - tag: Verification
    headline: Assume the verifier will be gamed
    body: The rewrite's checks rewarded matching output, and agents found the cheapest match. One imitated web search by copying text into files; the real fix, calling the internal service, took the team weeks. An audit of ported tests found more than 100 weakened assertions. After one agent guessed at Python's behavior, a rule said to port exactly what Python does, and a search found seven more guesses.

- id: try
  label: Try this week
  items:
  - tag: Experiment
    headline: Shadow one endpoint and fingerprint the differences
    body: 'Before an agent rewrites a service, give it a signal it can act on: the old service''s real behavior on real inputs, reduced to fingerprints that each point at one bug.'
    steps:
    - Pick one read-only or idempotent endpoint an agent is porting or refactoring, and mirror a sample of production requests to the new version without serving its responses.
    - Replay any expensive or nondeterministic dependency, such as a model call, from the old path into the new one, so nothing runs twice.
    - 'Compare at checkpoints, not just final output, and record only the shape of each mismatch: step, field, first differing byte, both lengths.'
    - Group mismatches by fingerprint, give the agent one fingerprint at a time, and require a test that fails before the fix and passes after.
    - Have a person review each fix for shortcuts, and turn every correction into a rule the next agent reads first.
    measure: Match rate on mirrored traffic, open fingerprints, and fixes rejected for gaming the check. Fingerprints that return after a fix ships mean the loop or the rules need work.
